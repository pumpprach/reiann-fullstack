# Reiann Product Spec

## เป้าหมาย

เว็บรวมข้อมูลวิชาสำหรับนิสิตมหาวิทยาลัยเกษตรศาสตร์ ที่ช่วยตัดสินใจเลือกวิชา วางแผนการเรียน และคำนวณเกรดได้ในที่เดียว

## ปัญหาที่ต้องการแก้

- เลือกไม่ถูกว่าควรลงวิชาอะไร และการอ่านรีวิวอย่างเดียวไม่พอต่อการตัดสินใจ
- วิชาเฉพาะของบางภาคไม่มีรีวิวใน KU Review
- อยากรู้ว่าคะแนนเก็บที่มีอยู่จะได้เกรดเท่าไร
- ไม่เห็นว่าวิชาที่เลือกจะต่อยอดไปสู่งานหรืออาชีพอะไรได้
- ไม่เห็นภาพว่าวิชาไหนเป็นตัวบังคับหรือตัวต่อของวิชาไหน
- ชีทสรุป ตารางเรียน วันสอบ และคำแนะนำจากรุ่นพี่กระจัดกระจาย ไม่มีที่แชร์กันโดยตรง

## Feature

### 1. ค้นหาและแนะนำวิชา

- ค้นหาและกรองตามหน่วยกิต หมวด GenEd วันเวลาเรียน รูปแบบเรียน และรูปแบบเก็บคะแนน
- เช็กเวลาเรียนชนกับตารางเรียนปัจจุบัน
- ตัวช่วยแนะนำวิชาจากคณะ ชั้นปี หน่วยกิตที่ขาด ความสนใจ และเวลาที่ว่าง พร้อมบอกเหตุผล
- ข้อมูลเชิงตัวเลขของแต่ละวิชา เช่น ปริมาณงาน ความยาก และความคุ้มค่า
- เทียบวิชา 2–3 วิชาข้างกัน
- เช็กหน่วยกิตตามหลักสูตร และแนะนำวิชาที่ช่วยเติมหมวดที่ขาด

### 2. ข้อมูลและรีวิววิชา

- หน้าวิชาครบทุกวิชาจากหลักสูตร แม้ยังไม่มีรีวิว
- รีวิวสั้น ให้คะแนนและเลือก tag ได้ในไม่ถึง 1 นาที
- ข้อมูลที่รุ่นน้องอยากรู้ เช่น รูปแบบสอบ ปริมาณงาน พื้นฐานที่ควรมี และเทคนิคผ่านวิชา
- แยกข้อมูลตามปีและอาจารย์
- คำขอรีวิว ("อยากรู้วิชานี้") เพื่อชวนคนที่เคยเรียนมาตอบ
- รีวิวแบบไม่แสดงชื่อ แต่ต้องยืนยันว่าเป็นนิสิต KU

### 3. คำนวณเกรด

- ใส่คะแนนตามสัดส่วนของวิชา
- คำนวณย้อนกลับว่าต้องได้ final เท่าไรจึงจะได้เกรดที่ต้องการ
- จำลองเกรดเมื่อ final ได้คะแนนต่างกัน
- ปรับเกณฑ์ได้ ทั้งแบบเกณฑ์ตายตัวและแบบอิงกลุ่ม โดยแบบอิงกลุ่มต้องบอกชัดว่าเป็นการประมาณ
- template สัดส่วนคะแนนของแต่ละวิชา ให้คนอื่นในวิชาใช้ต่อได้
- จำลองผลต่อ GPA/GPAX

### 4. เส้นทางอาชีพ

- เริ่มจากอาชีพ: ดูทักษะที่ต้องใช้และวิชาที่เกี่ยวข้อง
- เริ่มจากวิชา: ดูทักษะที่ได้และสายงานที่ต่อยอดได้
- แผนการเรียนตามสาย: วิชาบังคับ วิชาเลือก และลำดับที่ควรเรียนในแต่ละชั้นปี
- ประเมินแผนการเรียนว่าใกล้สายไหน และยังขาดทักษะอะไร
- ทักษะนอกห้องเรียน เช่น เครื่องมือ ใบรับรอง และโปรเจกต์ที่ควรทำเพิ่ม
- เส้นทางจากรุ่นพี่: เลือกเรียนอะไร และวิชาไหนได้ใช้จริง

หลักการ:

- เชื่อมข้อมูลผ่านทักษะ (`วิชา → ทักษะ → อาชีพ`) ไม่จับคู่วิชากับอาชีพตรง ๆ
- ใช้คำว่า "เกี่ยวข้องกับ" หรือ "ช่วยปูพื้นฐาน" ไม่ฟันธงว่าเรียนแล้วจะได้งาน
- แสดงที่มาของคำแนะนำและวันที่อัปเดต
- ให้รุ่นพี่หรืออาจารย์ในสายตรวจเส้นทางชุดแรกก่อนเผยแพร่

### 5. กราฟความเชื่อมโยงวิชา

พื้นฐาน:

- กราฟของแต่ละหลักสูตร ใช้ลูกศรบอกว่าต้องเรียนวิชาไหนก่อน
- เลือกวิชาแล้วไฮไลต์วิชาที่ต้องผ่านมาก่อนและวิชาที่เรียนต่อได้
- แยกวิชาบังคับก่อน วิชาที่ต้องเรียนพร้อมกัน และวิชาที่แนะนำให้เรียนก่อน
- จัดวางตามชั้นปีและภาค
- ค้นหาและกรองตามประเภทวิชา

ส่วนเสริม:

- ติ๊กวิชาที่ผ่านแล้ว เพื่อดูว่าตอนนี้ลงวิชาไหนได้ และวิชาไหนยังติดเงื่อนไข
- จำลองผลกระทบเมื่อตกหรือยังไม่ลงวิชา
- ชี้วิชาคอขวดที่ปลดล็อกวิชาอื่นจำนวนมาก
- เลือกอาชีพแล้วไฮไลต์เส้นทางวิชาที่เกี่ยวข้อง

การแสดงผล:

- เริ่มจากกราฟระดับหลักสูตร ไม่แสดงทั้งมหาวิทยาลัยพร้อมกัน
- บนมือถือมีมุมมองรายการ "ต้องเรียนก่อน / เรียนต่อได้"
- เครื่องมือที่พิจารณา: React Flow ร่วมกับ ELK หรือ Dagre

### 6. คลังชีทสรุป

- แชร์ชีทในหน้าวิชา แยกตามปี อาจารย์ และบท
- ช่วงแรกแนบเป็นลิงก์ เช่น Google Drive โดยยังไม่ต้องเก็บไฟล์เอง
- กด "ช่วยได้จริง" ได้ และแสดงจำนวนคนที่ได้ประโยชน์เป็นเครดิตให้ผู้แชร์
- แสดงว่าชีทใช้กับปีการศึกษาไหน เพื่อเตือนเมื่อเนื้อหาอาจไม่ตรงกับปีปัจจุบัน
- เลือกได้ว่าจะแสดงชื่อหรือไม่ และรายงานเนื้อหาที่ไม่เหมาะสมหรือละเมิดลิขสิทธิ์ได้

หลักการ:

- รับเฉพาะชีทที่เจ้าของทำเอง ไม่รับสไลด์หรือเอกสารของอาจารย์

### 7. แชร์ตารางเรียน

- ส่งตารางเรียนผ่านลิงก์ให้เพื่อนดูได้
- เทียบเวลาว่างกับเพื่อน
- ดูว่าเพื่อนลงวิชาหรือหมู่เรียนอะไร

หลักการ:

- ตารางเป็นส่วนตัวโดยค่าเริ่มต้น และแชร์เฉพาะคนที่เจ้าของอนุญาต
- ยกเลิกลิงก์ที่แชร์ไปแล้วได้ทุกเมื่อ

### 8. ถาม-ตอบรายวิชา

- ถามคำถามในหน้าวิชา โดยต่อยอดจากคำขอรีวิว ("อยากรู้วิชานี้")
- แจ้งเตือนคนที่เคยเรียนวิชานั้นให้มาตอบ
- กดว่าคำตอบไหนมีประโยชน์ และแสดงปีที่ผู้ตอบเรียน
- ถามหรือตอบแบบไม่แสดงชื่อได้ แต่ต้องยืนยันว่าเป็นนิสิต KU

### 9. ปฏิทินสอบและงานของวิชา

- คนในวิชาหรือหมู่เรียนช่วยกันใส่วันสอบและ deadline
- กดติดตามแล้วเห็นรายการรวมของทุกวิชาที่ลง พร้อมการแจ้งเตือนก่อนถึงกำหนด
- ช่วยกันยืนยันหรือแก้ไขวันที่ และแสดงว่าใครแก้ล่าสุดเมื่อไร

หลักการ:

- ข้อมูลมาจากนิสิต จึงต้องระบุชัดว่าไม่ใช่ประกาศทางการ และควรตรวจกับอาจารย์หรือแหล่งทางการ

### 10. แลกหรือขายหนังสือมือสอง

- ลงประกาศหนังสือหรือเอกสารเรียนโดยผูกกับรหัสวิชา
- ค้นหาจากหน้าวิชาหรือรหัสวิชาได้
- ปิดประกาศเมื่อแลกหรือขายแล้ว และรายงานประกาศที่ไม่เหมาะสมได้

หลักการ:

- เว็บเป็นเพียงพื้นที่ลงประกาศ ไม่รับชำระเงินและไม่เป็นตัวกลางในการซื้อขาย
- ผู้ลงประกาศต้องยืนยันว่าเป็นนิสิต KU และไม่แสดงช่องทางติดต่อต่อสาธารณะ

### 11. กลุ่มเรียน

กลุ่มเรียนคือกลุ่มเพื่อนที่เรียนด้วยกันทั้งเทอม เช่น แก๊งในหมู่เรียน ไม่ผูกกับวิชาใดวิชาหนึ่ง

- รวมตารางเรียนของสมาชิกเป็นตารางสัปดาห์เดียว แสดงช่วงที่เรียนด้วยกันทุกคน ช่วงที่บางคนมีเรียน และเวลาว่างตรงกัน
- แสดงวิชาที่สมาชิกตั้งแต่ 2 คนลงด้วยกัน พร้อมว่าอยู่หมู่เดียวกันหรือไม่
- รวมสอบและงานของทุกวิชาที่สมาชิกลง จากปฏิทินสอบและงาน
- นัดติวในช่วงว่างตรงกัน โดยเลือกวิชาหรือไม่ระบุวิชาก็ได้ และนัดที่ตอบว่าไปจะเข้าตารางเรียน
- กระดานของกลุ่ม แนบชีทหรือถามโจทย์ และติดป้ายวิชาเพื่อกรองได้
- ดูแผนเทอมหน้าของเพื่อน เพื่อวางแผนลงวิชาด้วยกัน

หลักการ:

- เข้าร่วมด้วยลิงก์เชิญหรือคำเชิญเท่านั้น สูงสุด 8 คน และต้องกดตอบรับก่อนกลุ่มจะเห็นตาราง
- สมาชิกเห็นวิชาและเวลาเรียนเสมอ ส่วนวันสอบและงาน และแผนเทอมหน้า แชร์ได้ตามที่เลือก
- ไม่แชร์เกรด GPAX หรือคะแนนในตัวคำนวณเกรด
- ออกจากกลุ่มแล้ว สมาชิกจะไม่เห็นข้อมูลของคุณทันที

## ลำดับการทำ

| ช่วง | ขอบเขต |
|---|---|
| **MVP** | หน้าวิชา, รีวิวสั้น, ค้นหาและกรองวิชา, ตัวคำนวณเกรด, กราฟวิชาพื้นฐาน, เส้นทางอาชีพ 3–5 สายสำหรับภาคแรก |
| **เฟส 2** | เช็กเวลาเรียนชน, เช็กหน่วยกิต, ติ๊กวิชาที่ผ่านแล้ว, ประเมินแผนการเรียน, คลังชีทสรุป, แชร์ตารางเรียน, ถาม-ตอบรายวิชา |
| **เฟส 3** | ตัวช่วยแนะนำวิชาเฉพาะบุคคล, จำลองผลกระทบ, เส้นทางจากรุ่นพี่, ปฏิทินสอบและงานของวิชา, แลกหรือขายหนังสือมือสอง, ขยายไปภาคอื่น |

## แนวทางข้อมูล

### แหล่งข้อมูล

- ไฟล์หลักสูตรที่เปิดเผยบนเว็บของมหาวิทยาลัยและคณะ เช่น registrar.ku.ac.th
- จากการค้นเบื้องต้นยังไม่พบ API ทางการ แต่ยังสรุปไม่ได้ว่าไม่มี
- ไม่ดึงข้อมูลจากระบบที่ต้องล็อกอิน เช่น my.ku.th เว้นแต่ได้รับอนุญาต

### ขั้นตอนการเก็บข้อมูล

1. สำรวจคณะ ภาควิชา และหลักสูตร พร้อมสถานะของไฟล์ต้นทาง
2. ทดลองกับ 1 คณะ เพื่อออกแบบฐานข้อมูลและวัดความแม่นยำ
3. ขยายทีละคณะ พร้อมอัปเดตรายงานความครบถ้วน

ขอบเขตเริ่มต้น: หลักสูตรปริญญาตรีที่ยังเปิดสอนอยู่

### ผลลัพธ์ที่ต้องการ

- ฐานข้อมูล SQLite และไฟล์ CSV
- ที่มาของทุกแถว: URL ต้นทาง เลขหน้า ปีหลักสูตร และวันที่ดึงข้อมูล
- รายงานว่าคณะหรือหลักสูตรไหนเจอแล้ว ไม่เจอ อ่านไม่ได้ หรือต้องให้คนตรวจ
- สคริปต์ที่รันซ้ำได้เมื่อมีหลักสูตรใหม่

### เงื่อนไขของวิชา

ต้องรองรับ:

- เงื่อนไขแบบ AND, OR และเงื่อนไขซ้อน เช่น (A หรือ B) และ C
- วิชาที่ต้องเรียนพร้อมกัน แยกจากวิชาบังคับก่อน
- เงื่อนไขที่ไม่ได้ระบุเป็นวิชา เช่น ชั้นปี 3 ขึ้นไป หรืออาจารย์อนุญาต

กติกา:

- เก็บข้อความเดิมจากหลักสูตรคู่กับเงื่อนไขที่แปลงแล้ว
- เก็บแยกตามปีหลักสูตร
- แยกเงื่อนไขทางการออกจากวิชาที่แนะนำ
- ถ้าไม่พบเงื่อนไข ให้บันทึกว่า "ไม่พบข้อมูล" ห้ามตีความว่าไม่มีวิชาบังคับ
- ตรวจเงื่อนไขที่วนกัน และการอ้างรหัสวิชาที่ไม่มีอยู่

## แนวทาง AI

| ประเภทคำถาม | วิธีตอบ | ตัวอย่าง |
|---|---|---|
| ข้อเท็จจริงที่ต้องแม่นยำ | ฐานข้อมูล (SQL) | หน่วยกิต, วิชาบังคับก่อน, หน่วยกิตที่ยังขาด |
| ความหมายหรือความเกี่ยวข้อง | RAG + LLM | อยากเป็น Data Analyst ควรลงวิชาอะไร |
| ต้องใช้ทั้งสองอย่าง | SQL กรองก่อน แล้วให้ RAG + LLM จัดอันดับและอธิบาย | แนะนำวิชาเลือกสายข้อมูลที่ยังลงได้ |

- embedding ต้องมี metadata สำหรับกรองตามหลักสูตรและปี
- คำตอบต้องอ้างอิงแหล่งที่มา ถ้าไม่พบข้อมูลต้องตอบว่าไม่พบ
- ก่อนเปิดใช้ ทดสอบด้วยคำถามจริงพร้อมเฉลย 30–50 ข้อ

## ข้อจำกัด

- **สิทธิ์การใช้ข้อมูล:** ยังไม่พบเงื่อนไขการใช้งานเว็บหรือนโยบายลิขสิทธิ์ของ KU ก่อนเปิดเว็บสาธารณะควรสอบถามสำนักบริหารการศึกษาหรือหน่วยงานเจ้าของข้อมูล
- **ข้อมูลส่วนบุคคล:** เอกสารหลักสูตรอาจมีชื่อและประวัติอาจารย์ จึงเก็บเฉพาะข้อมูลวิชาที่จำเป็น
- **ความครบถ้วน:** ไฟล์หลักสูตรกระจัดกระจาย บางส่วนอาจเก่าหรือไม่ได้เปิดเผย จึงไม่รับประกันว่าครบ 100%
- **ความถูกต้อง:** PDF สแกนหรือภาษาไทยที่เพี้ยนอาจทำให้ดึงข้อมูลผิด ควรให้คนในสาขาช่วยตรวจ
- **ความเป็นปัจจุบัน:** แสดงปีหลักสูตรและวันที่อัปเดต และเตือนให้ตรวจกับแหล่งทางการก่อนลงทะเบียน
- **ข้อมูลตั้งต้น:** เริ่มจากภาคแรกและเก็บรีวิวจากเพื่อนและรุ่นพี่ให้ได้สัก 20–30 วิชา
- **ลิขสิทธิ์ของเนื้อหาจากผู้ใช้:** ชีทอาจมีเนื้อหาจากเอกสารของอาจารย์ จึงต้องมีกติกาการแชร์ การรายงาน และการลบเนื้อหา
- **ความเป็นส่วนตัวของตารางเรียน:** ตารางเรียนบอกได้ว่านิสิตอยู่ที่ไหนในแต่ละช่วงเวลา จึงต้องไม่เปิดเป็นสาธารณะ
- **ความถูกต้องของข้อมูลจากผู้ใช้:** วันสอบและ deadline อาจผิดหรือเปลี่ยนภายหลัง จึงต้องแสดงที่มาและเวลาที่แก้ล่าสุด
- **การซื้อขายระหว่างนิสิต:** เว็บไม่รับประกันสินค้าหรือการซื้อขาย และต้องแจ้งข้อนี้ในหน้าลงประกาศ
- **หน้าวิชาที่ยังไม่มีเนื้อหาจากผู้ใช้:** ข้อมูลวิชาต้องเป็นส่วนหลัก เพื่อให้หน้ายังใช้งานได้แม้ไม่มีชีท คำถาม หรือประกาศ

## คำถามที่ยังค้างอยู่

- จะใช้คณะไหนเป็นคณะทดลอง
- ภาคแรกที่จะทำเส้นทางอาชีพคือภาคอะไร และมีสายอาชีพใดบ้าง
- มหาวิทยาลัยอนุญาตให้นำข้อมูลหลักสูตรมาเผยแพร่ซ้ำได้แค่ไหน
- มี API หรือแหล่งข้อมูลรายวิชาทางการที่ใช้แทนการอ่าน PDF ได้หรือไม่
- จะอนุญาตให้แชร์ข้อสอบเก่าหรือไม่ และมหาวิทยาลัยมีกฎเรื่องนี้อย่างไร
- ผู้ซื้อและผู้ขายหนังสือจะติดต่อกันอย่างไรโดยไม่เปิดเผยช่องทางติดต่อต่อสาธารณะ
